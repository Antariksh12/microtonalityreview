# Beyond Pitch — Conference Presentation

**Title:** Beyond Pitch: A Review of Microtonality in Indian Classical Music  
**Author:** Antariksh Pasricha, Research Scholar, National Institute of Advanced Studies, Bengaluru

## Open locally
Open `index.html` in Chrome/Edge/Firefox. Use **← / →**, Page Up/Page Down, Space, Home and End to navigate.

## Host on GitHub Pages
1. Create a new GitHub repository (for example `beyond-pitch`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then Save.
6. GitHub will provide a public Pages URL such as `https://YOUR-USERNAME.github.io/beyond-pitch/`.

## Presentation design
The deck is responsive, uses no JavaScript libraries, and contains original inline SVG diagrams for continuous pitch, the 22-śruti discussion, and pitch trajectories. Three contextual images load from Wikimedia Commons.

## Academic caution
The deck deliberately avoids equating śruti with a modern JND or presenting the 22-śruti tradition as one universally fixed frequency grid. It distinguishes theoretical tuning, performed intonation, and listener perception.
